# Мост аддона

Панель аддона и OmniPanel общаются сообщениями `postMessage`.

## Запрос от аддона

```js
parent.postMessage({ omni: 1, rid: 7, method: 'read', args: ['server.properties'] }, '*');
```

* `omni: 1` — метка «это аддон»;
* `rid` — любое число, по нему находится ответ;
* `method` — что сделать, `args` — массив аргументов.

## Ответ панели

```js
{ omni: 2, rid: 7, ok: true, data: { /* ... */ }, error: '' }
```

Помимо ответов панель присылает служебные сообщения:

| type | Когда | Что внутри |
|---|---|---|
| `init-ok` | ответ на `init` | `server: { id, name, running }`, `theme` |
| `theme` | сменили тему или скругления | `theme` |
| `server-changed` | переключили сервер | `server` |

## Методы

| Метод | Аргументы | Что делает | Право |
|---|---|---|---|
| `init` | — | рукопожатие, отдаёт сервер и тему | — |
| `list` | `path` | список файлов папки: `{ items: [{ name, path, isDir, size }] }` | `files` |
| `read` | `path` | текст файла: `{ content, size, path }` | `files` |
| `write` | `path`, `content` | записать файл (папки создаются) | `files` |
| `props` | `{ ключ: значение }` | изменить `server.properties` с сохранением комментариев | `files` |
| `command` | `текст` | отправить команду в консоль сервера (нужен запущенный сервер) | `command` |
| `openEditor` | `path` | открыть файл в системном редакторе | — |
| `lookupUuid` | `ник` | UUID игрока через Mojang: `{ uuid }` | — |

## Пути

Все пути — **относительно папки сервера**: `MythicMobs/Mobs/King.yml`, а не `C:\server\...`.
Выйти за пределы папки нельзя: панель отклонит `..` и абсолютные пути.

## Пример: прочитать и записать конфиг

```js
let rid = 0;
const waits = new Map();
function call(method, args = []) {
  return new Promise((resolve) => {
    const id = ++rid;
    waits.set(id, resolve);
    parent.postMessage({ omni: 1, rid: id, method, args }, '*');
    setTimeout(() => { if (waits.has(id)) { waits.delete(id); resolve({ ok: false, error: 'нет ответа' }); } }, 15000);
  });
}
window.addEventListener('message', (e) => {
  const d = e.data;
  if (!d || d.omni !== 2 || !waits.has(d.rid)) return;
  waits.get(d.rid)(d);
  waits.delete(d.rid);
});

const file = await call('read', ['config.yml']);
if (file.ok) {
  const text = file.data.content.replace('enabled: false', 'enabled: true');
  await call('write', ['config.yml', text]);
}
```
