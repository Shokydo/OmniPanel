# Создание аддона

Аддон — обычная папка. Клади её в `OmniPanelData/addons/<id>` (свои) — панель подхватит при следующем
открытии вкладки «Настройки → Аддоны». Встроенные аддоны лежат в `assets/addons/<id>`.

## Манифест `addon.json`

```json
{
  "id": "my-addon",
  "name": "Мой аддон",
  "version": "1.0.0",
  "author": "Ник",
  "description": "Что делает аддон — одно предложение",
  "icon": "М",
  "panel": { "title": "Мой аддон", "file": "panel.html" },
  "permissions": ["files", "command"],
  "defaultEnabled": false
}
```

| Поле | Обязательное | Что значит |
|---|---|---|
| `id` | да | латиница, цифры, `-`, `_`, `.`; от 2 до 41 символа |
| `name` | нет | название во вкладке и в списке |
| `panel.file` | нет | HTML панели рядом с манифестом; без него аддон без вкладки |
| `permissions` | нет | `files` — файлы сервера, `command` — консоль |
| `defaultEnabled` | нет | `false` — аддон выключен, пока его не включат вручную |

## Панель `panel.html`

Это отдельный документ, он живёт в изолированном окне (iframe sandbox) и **не имеет доступа**
к панели напрямую — только через мост (см. [Мост аддона](Мост-аддона)).

Обязательный минимум:

```html
<!doctype html>
<html lang="ru"><head><meta charset="utf-8"></head>
<body>
<script>
  parent.postMessage({ omni: 1, rid: 1, method: 'init', args: [] }, '*');
  window.addEventListener('message', (e) => {
    const d = e.data;
    if (!d || d.omni !== 2) return;
    if (d.type === 'init-ok') {
      // d.server — { id, name, running }, d.theme — цвета и скругления
    }
  });
</script>
</body></html>
```

## Оформление

Тема приходит в `d.theme`: `bg`, `panel`, `panel3`, `line`, `text`, `dim`, `accent` и `radius`
(`xs`, `sm`, `md`, `lg`, `pill`, `circle`, `card`). Применяй их как CSS-переменные — тогда аддон
перекрашивается вместе с панелью и уважает режим «квадрат / мягкие / круглые / таблетки»:

```js
const r = document.documentElement.style;
r.setProperty('--bg', theme.bg);
r.setProperty('--r-sm', theme.radius.sm);
```

Если тема поменялась, панель пришлёт сообщение `{ type: 'theme', theme }` — перепримени.

## Правила

* Никаких `title`-подсказок: текст пишется рядом с элементом.
* Только переключатели, не чекбоксы.
* Ошибки показывай текстом в панели, а не `alert`.
* Всё, что аддон делает с сервером, должно быть видно: путь файла, команда, результат.
