# OmniPanel

Панель для майнкрафт-серверов на Windows: один `.exe`, без Node.js и без браузера.
Серверы в одном окне — консоль, файлы, бэкапы, плагины, игроки, производительность,
синхронизация с GitHub или GitLab и аддоны.

## Что есть

* **Серверы** — создание, запуск, остановка, перезапуск, автоперезапуск при падении, порт и память.
* **Консоль** — живой вывод в цвете, фильтр, отправка команд, сохранение лога в файл.
* **Файлы** — дерево сервера, редактор с подсветкой, drag & drop, архивы и картинки внутри панели, до 16 вкладок.
* **Бэкапы** — 7z/LZMA2 с максимальным сжатием, «лёгкий» бэкап без libraries и логов,
  восстановление, авто-бэкап по расписанию, лимит хранения.
* **Плагины** — поиск и установка с Modrinth прямо из панели.
* **Игроки** — онлайн-список с обновлением без нажатий, режим игры, очистка инвентаря,
  кик, убийство и бан; отдельная вкладка блокировок с ником, UUID, IP и разбаном.
* **Производительность** — CPU, RAM, TPS с историей и автообновлением.
* **GitHub и GitLab** — весь сервер архивом частями по 20 МБ: у GitHub это репозиторий
  (или пофайлово), у GitLab — хранилище пакетов проекта.
* **Аддоны** — расширения с собственной панелью, их можно выключать.

## Принципы

* Чёрно-белой основы нет — тема выбирается, включая «квадратную» и «таблетки»; скругления
  применяются ко всему интерфейсу и к панелям аддонов.
* Никаких подсказок-тултипов: всё, что нужно знать, написано рядом с элементом.
* Только переключатели, без чекбоксов.
* Обновления: код ставится сам, полная сборка — только с согласия пользователя.
