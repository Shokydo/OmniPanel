# Установка и первый запуск

## Один файл

Скачай `OmniPanel-Установка-X.Y.Z.exe` из раздела Releases и запусти. Внутри уже вся панель (~100 МБ),
Node.js ставить не нужно.

1. **«Установить»** — панель раскладывается в `%LOCALAPPDATA%\OmniPanel`, права администратора не нужны.
2. Установщик создаёт ярлыки на рабочем столе и в меню «Пуск».
3. **«Запустить панель»** — панель открывается.

SmartScreen может предупредить о неподписанном exe: «Подробнее» → «Выполнить в любом случае».

## Где лежат данные

`OmniPanelData` рядом с программой: `servers.json`, `panel.json`, `addons.json`,
`backups/`, `addons/`. Переносишь папку на другой ПК — настройки едут с ней.

## Первый сервер

1. **«Создать сервер»** — название, команда запуска (`java -Xmx4G -jar server.jar nogui`), рабочая папка.
2. **«Добавить существующий»** — если папка с сервером уже есть: панель сама найдёт `server.properties`.
3. **«Из GitHub»** — клонирование сервера из репозитория или из архива.

## Порт занят

Если порт уже держит другой сервер или программа, панель покажет окно **«Порт занят»**
с подсвеченным свободным портом и кнопкой **«Сменить и запустить»** — новый порт запишется
в `server.properties`.

## Полный экран

F11 — полный экран. Шапка остаётся той же, что и в окне: логотип, ник аккаунта, состояние сервера,
кнопки управления. Двойной клик по шапке возвращает в окно.

## Обновления

Настройки → «Обновления»: панель проверяет `update.json` в репозитории, код ставит автоматически,
полную сборку — только с твоего согласия, чтобы не сломать запущенные серверы.
