Действия
Что это значит
Код панели обновляется сам: качается маленький архив с GitHub и заменяет файлы программы — перекачивать сборку целиком не нужно. Полная сборка (новый exe) скачивается только по кнопке и ставится отдельным ярлыком «Обновить-OmniPanel.bat» рядом с папкой программы. Перед заменой файлы панели копируются в бэкап. Настройки, список серверов, профиль GitHub, история TPS и миры не трогаются: обновление заменяет только код панели. При включённой автоустановке панель обновляется сама при запуске (а если работали серверы — при закрытии).
