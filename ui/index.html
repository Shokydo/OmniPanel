Синхронизация с GitHub
Синхронизация всего сервера
мир, плагины, конфиги и ядро целиком — в один репозиторий GitHub. Логи, кэш и бэкапы не отправляются.
Отправка: панель упаковывает папку сервера в 7-Zip и делит архив на части по 45 МБ — каждая часть проходит лимит GitHub. Забор: скачивает все части, проверяет контрольные суммы, распаковывает и удаляет части из репозитория, чтобы он не распухал. Оставь переключатель «оставлять части» включённым, только если архив нужен в репозитории как копия.
