# Переезд OmniPanel на Rust — где мы сейчас

Версия панели на диске: **1.26.0**. Ничего в рабочей панели не сломано:
переезд идёт рядом, отдельным Rust-ядром, и подключается только тогда,
когда очередной кусок проверен тестами.

## 1. Что уже сделано

### Ядро `rust/omnipanel-core` — 64 теста, все зелёные

Без единой внешней зависимости (только стандартная библиотека), поэтому
собирается быстро и без интернета.

| Модуль | Что умеет | Тестов |
|---|---|---|

| `props` | чтение и запись `server.properties` с сохранением комментариев, `\uXXXX` как в Java | 10 |
| `files` | папки сервера: список, чтение/запись, создание, удаление, переименование, перенос, поиск, подпись папки, защита от выхода за корень, cp1251 | 11 |

| `app` | разбор каналов интерфейса, срезы «серверы и файлы», `servers.json` под рукой у панели | 13 |

### Мост «интерфейс → Rust»: `ui/tauri-bridge.js`

Собирается автоматически из `preload.js`:

```
node tools/gen-tauri-bridge.js
→ мост собран: ui/tauri-bridge.js
  всего методов: 153 (команды 130, события 21, отправка 2)
```

Это важно: интерфейс не переписывается. В `ui/app.js:192` стоит
`const API = window.desktop || httpApi;` — в Tauri `window.desktop` создаёт
этот мост, и все 130 команд идут в Rust. Пока команда не перенесена, она
отвечает понятной ошибкой, а не молча ломает окно.

### Каналы: перенесено 26 из 152

```
node tools/gen-tauri-bridge.js
→ перенесено в Rust: 26 из 152 каналов
  ещё не перенесено (126): gh:18, upd:11, win:9, load:8, wizard:7, addons:6, ...
```

Живут в Rust: `servers:*` (8), `server:start/stop/restart/kill/command/logs/clearLogs` (7),
`files:*` (9), `app:info`, `path:check`.

Две мелочи, без которых интерфейс ломался бы молча:

* файловые каналы **не бросают ошибку**, а отдают `{ok:false, error}` — интерфейс
  проверяет `res.ok === false || res.error` (как `fsWrap` в прежнем `main.js`);
* у сервера без `cwd` канал файлов отвечает `«У сервера не задана рабочая папка»`,
  а не пустым списком.

## 2. Два решения, которые поменяли план

**Сервер запускается строкой команды через оболочку, а не «java + jar».**
В панели `core/manager.js:398` стоит `spawn(srv.command, [], { shell: true })`.
Значит в Rust: `sh -c "<команда>"` (на Windows `cmd /C "<команда>"`).
Так работают и `java -jar server.jar nogui`, и `start.bat`, и `./run.sh`,
и питон-боты — то есть ровно то, что у игроков в настройках уже написано.

**Состояний только три: `stopped`, `running`, `stopping`.**
В интерфейсе (`ui/app.js:2888`) других нет, поэтому ядро не выдумывает
`starting`: сервер считается работающим сразу после запуска, как и раньше.

## 3. Как проверить

```bash
cd /home/user/OmniPanel/rust/omnipanel-core
PATH=/home/user/build/root/bin:$PATH \
CARGO_HOME=/home/user/build/cargo CARGO_TARGET_DIR=/home/user/build/target \
cargo test --offline
```

Ожидаемо: `13 + 11 + 11 + 10 + 19 = 64 passed; 0 failed` (около 5 секунд —
тесты поднимают настоящие процессы, ждут живой лог и мягкую остановку).

Если Rust пропал (папка `build/` не переживает снапшот), ставим заново:

```bash
mkdir -p /home/user/build/dl && cd /home/user/build/dl
for c in rustc rust-std cargo; do
  curl -sSL -o $c.tar.xz https://static.rust-lang.org/dist/$c-1.85.1-x86_64-unknown-linux-gnu.tar.xz
  tar -xf $c.tar.xz && (cd $c-1.85.1-x86_64-unknown-linux-gnu && \
    ./install.sh --prefix=/home/user/build/root --disable-ldconfig >/dev/null)
done
```

## 4. Что дальше, по шагам

1. ~~Каналы `servers:*`, `server:*`, `files:*`~~ — готово (26 из 152).
2. **Доделать «серверы и файлы»**: `archive:*` (список и распаковка zip),
   `files:upload/openExternal/editor`, `ports:*` (проверка и смена занятого порта),
   `props:*` (`server.properties`), `server:autoFolder`, `tps:*`, `scan:*`, `icon:*`, `bans:*`.
3. **Оболочка Tauri 2**: окно без рамки, своя шапка, трей, F11, скрытие в трей.
4. **Логи, консоль, метрики** — события `log`, `state`, `metrics` в окно.
5. **GitHub/GitLab-синхронизация** — заливка в 4–6 потоков вместо
   последовательной (`core/gitlab.js:285`), это ещё и ускорение.
6. **Обновления** — `upd:*`, проверка sha256, автоматическая установка кода.
7. **Аддоны** — JS-движок внутри Rust (boa или quickjs).
8. **Тестовые боты и нагрузка** — последними: они самые «многофайловые».

**Договорённость с владельцем панели:** пока Rust-сборка не догнала панель,
релизы не выпускаются — рабочая версия остаётся 1.26.0 на Electron.

Оценка целиком — 2–4 месяца. Промежуточные шаги безопасны: пока Rust-сборка
не догнала панель, обновления продолжают ставиться на текущую версию.
